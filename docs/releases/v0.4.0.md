# v0.4.0 · 菜单栏直达 agent 视图 + Skill 健康检查

## 本次更新

### 菜单栏：点 agent 行直达主窗口

- 状态栏面板里每个 agent 行可点击：主窗口前置并只显示该 agent 的 skill，同时清空搜索词
- 面板恢复 window 样式（hover 高亮、行级交互），点击 agent 行后自动收起
- 右键 agent 行保留「在 Finder 中显示」其 skill 根目录
- 主窗口关闭后点 agent 行可重新打开并筛选正确

### Skill 健康检查 v1

扫描时顺路收集每条 skill 的客观健康事实，只报事实、零阈值判定：

- **frontmatter 完整性**：缺少 frontmatter 块 / 缺 `name` / 缺 `description`
- **结构异常**：SKILL.md 为空、非 UTF-8 编码、目录内符号链接指向空目标
- **体积事实**：目录总大小、SKILL.md 大小、文件数（agent 实际加载口径）
- 列表行黄色 ⚠️ 徽章标记有问题的 skill；详情面板新增「健康」区块逐条列出；无问题时只显示一行体积事实，零噪音

### In this release

**Menu bar: click an agent row to jump into the main window.** Each agent row in the status-bar panel now opens the main window filtered to that agent and clears the search field. The panel is back to the window style (hover highlight, per-row interactions) and auto-dismisses after clicking. Right-click still offers "Show in Finder" for the agent's skill root.

**Skill health check v1.** Scanning now collects objective health facts per skill — no thresholds, facts only:

- **Frontmatter completeness**: missing frontmatter block / missing `name` / missing `description`
- **Structural issues**: empty SKILL.md, non-UTF-8 encoding, dangling symlinks
- **Size facts**: total folder size, SKILL.md size and file count (what the agent actually loads)
- Rows with issues get a yellow ⚠️ badge; the detail pane lists each issue under a new Health section. Healthy skills show just one quiet line of size facts.

412 tests passing, zero build warnings. Requires macOS 15+. The app is ad-hoc signed and not notarized — right-click → Open on first launch if Gatekeeper blocks it.
