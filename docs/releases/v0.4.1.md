# v0.4.1 · 生效关系与落点修复

> 生效日期：2026-11-09 · 类型：patch

## ✨ 新增：生效关系（详情区块）

回答一个此前没人能回答的问题：**目录里这么多 skill，agent 实际加载的是哪一个？**

详情面板新增「生效关系」区块，覆盖三类事实：

- **同名遮蔽**：同一 agent 内同名 skill 同时存在项目级与用户级副本时，明确标注哪个真正生效——依据 Claude Code 官方文档（项目级 > 用户级）硬编码判定；被遮蔽副本显示 👁️‍🗨️ 提示，生效副本显示遮蔽数量。
- **多 agent 共同加载**：同一内容被多个 agent 目录引用时列出全部归属。
- **用户级串扰提示**：提醒用户级 skill 目录可能被其他工具读取。

原则不变：**只报有官方依据的客观事实**。无优先级文档的 agent 不判定（宁可少说）；无任何关系信息时整个区块不渲染（零噪音）。

## 🔧 修复

- **同名落点重复显示**：multiAgent（多 agent 共载）副本在「同名安装」面板被展开成重复行且错误归属（如宣称 Claude Code 加载 `~/.agents` 目录）；现改为每个目录一行、归属 agent 合并显示。
- **sha256 独立成行**（v0.4.0 回归修复）：详情页 sha256 不再与上一行粘连。

# v0.4.1 (English)

## ✨ New: Effect Relations (detail section)

Answers the question no tool could answer before: **with this many skills in my directories, which one does the agent actually load?**

The detail panel gains an "Effect" section covering three facts:

- **Same-name shadowing**: when a same-named skill exists at both project and user level for one agent, the section states which copy takes effect — hardcoded from Claude Code's official docs (project > user). Shadowed copies get an eye-slash notice; effective copies show the shadowed count.
- **Multi-agent sharing**: lists every agent that loads shared content.
- **User-level cross-read note**: user-level skill directories may also be read by other tools.

Principles unchanged: **objective facts backed by official documentation only**. Agents without documented precedence are not judged; the section is not rendered when there is nothing to say (zero noise).

## 🔧 Fixes

- **Duplicate same-name landing rows**: multiAgent copies used to expand into duplicate rows with wrong ownership in the "Same-name Copies" panel; now one row per directory with merged owners.
- **sha256 on its own line** (v0.4.0 regression fix).
