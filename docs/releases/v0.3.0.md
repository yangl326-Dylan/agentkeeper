## 本次更新

设置页新增「关于与更新」，可以手动检查 GitHub 上的最新版本，并在 App 内完成原地更新。

### 应用内更新

- 显示当前版本，手动检查 `releases/latest`
- 发现新版本后直接下载官方资产、校验、替换当前 `.app` 并自动重启
- 安装前校验 `CFBundleShortVersionString` 与 Bundle ID（`app.agentkeeper.mac`）
- 只接受 HTTPS + GitHub 域名资产
- 后台脚本等待进程退出后替换；失败自动回滚并重新打开旧版本
- 菜单栏、Dock、侧栏、启动弹窗均无更新标记——只在设置页呈现

### 自定义 agent（v0.2.0 起）

写 `~/.agentkeeper/agents.json` 即可接入内置列表之外的 agent，无需重新编译或等发版。见 [接入指南](https://github.com/yangl326-Dylan/agentkeeper/blob/main/docs/adding-an-agent.md)。

### 质量

- `swift build`：0 error / 0 warning
- `swift test --no-parallel`：392 tests passed

### 安装

- App：下载 `AgentKeeper-app-macos.zip`，解压后把 `AgentKeeper.app` 拖入 `/Applications`
- CLI：下载 `AgentKeeper-cli-macos.zip`，解压后把 `ak` 安装到 `/usr/local/bin`
- 需要 macOS 15+

> App 为 ad-hoc 签名、未公证。首次启动如被拦截，请在 Finder 中右键 → 打开。
