# v0.5.0 · DeepSeek Harness 支持

> 发布日期：2026-11-09 · 类型：minor

## 🎉 新增：DeepSeek Harness（内置 agent）

AgentKeeper 现已收录 **DeepSeek Harness**（`dsh`，developer preview）为第 11 个内置 agent：

- 用户级 `~/.dsh/skills`、项目级 `<projectRoot>/.dsh/skills` 全覆盖
- **双形态扫描**：目录包 `<name>/SKILL.md` 与官方同款支持的**扁平单文件 `<name>.md`**（root 直属）都能扫出来
- 判定依据：DeepSeek Harness 官方文档的 rank 发现规则（100 项目 / 400 用户）

## 👁️ 生效关系升级：遮蔽判定覆盖 DeepSeek

DeepSeek Harness 是少数有**官方优先级文档**的 agent——同名 skill 时项目级（rank 100）生效、用户级（rank 400）被遮蔽。AgentKeeper 依据官方文档硬编码判定，详情面板明确标注「哪个真正生效」，与 Claude Code 同款待遇。

> 原则不变：只报有官方文档背书的客观事实，宁可少说。

## 📑 扁平 skill 详情（只读）

扁平单文件 skill 的详情页完整可用：SKILL.md 预览、文件清单、指纹与健康事实。在线操作（停用 / 安装到其他 agent / 回收站）暂不支持，界面明确提示——不提供半途而废的操作。

## 已知边界（明示不做）

- `~/.agents/skills`（dsh rank 500）仍归 Agents 共享目录，与 deepseek 的共同加载关系暂不展示
- dsh 的 `customSkillDirs` / `bundledSkillDir` 配置目录无法感知（Config 注入，不在文件系统约定内）
- 扁平 skill 在线操作（v2 再议）

# v0.5.0 (English)

## 🎉 New: DeepSeek Harness (built-in agent)

AgentKeeper now ships **DeepSeek Harness** (`dsh`, developer preview) as its 11th built-in agent:

- User-level `~/.dsh/skills` and project-level `<projectRoot>/.dsh/skills`
- **Both skill shapes scanned**: directory packages (`<name>/SKILL.md`) and **flat single-file skills** (`<name>.md` directly under a root), matching the official discovery semantics
- Based on the official Harness docs rank table (100 project / 400 user)

## 👁️ Effect relations: shadowing now covers DeepSeek

DeepSeek Harness is one of the few agents with a **documented precedence rule** — on same-name collisions the project-level copy (rank 100) wins and the user-level copy (rank 400) is shadowed. AgentKeeper hardcodes exactly that, and the detail panel now states which copy is in effect, same as Claude Code.

> Principle unchanged: objective facts backed by official documentation only.

## 📑 Flat skill details (read-only)

Flat skills get a fully working detail panel: SKILL.md preview, file list, fingerprint and health facts. In-app operations (disable / install to other agents / trash) are not supported yet and the UI says so explicitly — no half-working buttons.

## Known limits (explicitly not done)

- `~/.agents/skills` (dsh rank 500) stays under the shared-agents directory; the co-loading relation with deepseek is not shown yet
- dsh `customSkillDirs` / `bundledSkillDir` (Config-injected) cannot be detected
- Flat-skill in-app operations (planned for v2)
