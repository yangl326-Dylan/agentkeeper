# 收藏匣 · Keeper's Vault —— AgentKeeper 图标设计哲学

> 2026-11-02 · App 图标（AppIcon.icns）+ 状态栏字形（MenuBarExtra template）共用一套视觉母题。

## 哲学：One More Slot（永远留一格）

AgentKeeper 的产品本质是「收纳的持续态」——外部散落的 skill 被保管员（keeper）
一件件编目、对账、快照。所以图像语言不去画「管理面板」，而是画**收纳正在进行中的那一瞬**：
匣子开着，格架整齐，有一格永远空着，一张卡正在滑入。

1. **纸面上的主体**。底色用 Claude 品牌象牙纸（#FAF9F5 → #F1EEE7 微光渐变），
   不做满铺渐变的压迫感——图形悬浮在纸面上，像盖了印的信笺。这是 Claude 设计语言
   的第一性：大面积留白 + 单一陶土色主体，克制到近乎文书。

2. **一只开口的匣**。主体是圆角「保管匣」：陶土橙（#D97757 → #BF5E3E）细渐变
   质感 + **中央镂空**（even-odd 剪裁）——镂空让纸面透出来，匣子因此「开着」。
   镂空内部上缘一道极淡的内阴影，暗示深度，只是深度，不做拟物光影堆砌。

3. **格架上的编目秩序**。镂空区内 2×2 圆角卡片格，其中三格是象牙卡（已收纳的
   skills），右上留空。空的不是缺陷，是字符——「还有下一格」。卡片一律圆角
   统一、间距均一，秩序感全部来自这组等距关系的精确，而非任何装饰。

4. **正在滑入的炭色卡**。第四颗元素是深炭（#262624）圆角卡，以 -10° 的动势半嵌
   在空格旁、越过匣口一线，身后两道细虚线是速度的痕迹。「新 skill 进入编目」
   的动势让整幅静物有一个短暂的动词。它也是全图唯一的深色重音——整幅构图的
   视觉落点。

5. **每件作品都像反复打磨过千百遍**。所有数值（圆角、内距、卡宽、虚线间隔）
   均按 1024 母版手定再等比缩放，小尺寸独立重渲（不是缩位图）——16pt 下依然
   是同一件静物。状态栏字形是同一母题的极简投影：**托盘描边 + 2×2 三实一空**，
   单色 template，菜单栏明暗自适应。它的留白比 App 图标更多，因为目标尺寸
   只有 18pt——那里只允许讲一句话：*收录还在继续*。
