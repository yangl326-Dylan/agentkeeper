# i18n 国际化设计（中文 / English，设置切换，默认同系统）

日期：2026-11-04
状态：已实现（用户授权直接执行）

## 需求

界面支持简体中文与 English；设置页可切换；默认跟随系统首选语言；切换即时生效。

## 方案（代码级 L10n，非 .xcstrings）

选型约束：本项目是 SwiftPM 裸可执行 + 自组装 .app（`scripts/build-app.sh`），没有 Xcode 构建系统参与，`.xcstrings` 字符串目录无法自动编译出 `.lproj`。因此采用**编译期属性键控的字符串表**：

- `AppCore/L10n.swift`：`AppLanguage`（system/zhHans/english）+ `ResolvedLanguage` + `L10n` 结构体（约 150 个计算属性，zh/en 双语内联）。AppCore 层（导航标题、区标题）与 UI 层共用；Foundation-only，无 SwiftUI 依赖。
- 拼错键名 = 编译错，不存在运行时 miss；中英文案相邻可维护。
- 语言解析：`AppLanguage.resolveSystem(preferredLanguages:)` —— 首选语言 `zh*` → zhHans，否则 english（`Locale.preferredLanguages`）。

## 状态流

```
AppSettingsStore.language (defaults "language.v1", @Observable)
  → AppEnvironment.l10n (计算属性)
  → 各视图读取 env.l10n / 传参 l10n（语言切换即时全 UI 刷新）
```

## 迁移范围

全量 UI 面：侧栏、Skill 列表/详情/工具条、Zone 列表（停用区/回收站 + 不可逆确认弹窗）、菜单栏面板（MenuBarPanel/MenuSummarySection）、引导页、设置页、总览仪表盘、⌘R 命令菜单、状态条、文件清单、Markdown 预览。AppCore 侧：`SidebarNode` 标题、`LifecycleZone.title(l10n:)`、`ScopeKind.label(l10n:)`。

组件带默认参数 `var l10n: L10n = L10n(lang: .zhHans)`（离屏快照测试可无 env 渲染）；有 env 的视图一律传 `env.l10n`。

## 范围外（YAGNI，记 backlog）

- 服务层错误文案（DistributionService.friendly / OperationError / ScanService.errorFriendly）：保持中文，后续按 error code → L10n 收敛。
- SkillPreviewModel.loadMarkdown 改为返回 `String?`（缺失 → nil），空串哨兵区分「缺失」与「加载中」，占位文案由 UI 按语言渲染。
- 更多语种：加 ResolvedLanguage case + L10n 属性分支即可扩展。

## 测试

- 既有文案断言迁移为双语断言（ScanStatusTextTests / NavigationModelTests.nodeTitles）。
