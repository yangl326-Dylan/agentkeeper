# README 产品截图（标杆场景）设计

日期：2026-11-12
状态：已确认

## 目标

为 README（中英双语）补充真实产品图例，展示标杆场景，提升 GitHub 首屏说服力。

## 需求确认

- 形式：**真实截图**（不使用 AI 生成示意图）
- 场景：**三场景套图** —— 主界面（统一目录 + 三维度筛选）、同名分歧检测、健康检查，外加一张真实终端的 `ak` 输出图
- 主题：**浅色模式**（截图时临时切换系统外观，截完恢复）
- 数据：使用本机真实 skill 数据，不脱敏（用户已确认）
- 位置：hero 图放双语 tagline 之后；场景图嵌入「功能」段对应位置；CLI 图放「CLI 速览」段

## 方案

AppleScript + `screencapture -l <windowID>` 按窗口截图（无阴影、@2x）。
页面切换优先 AppleScript UI 脚本；若无辅助功能权限，则请用户手动切换页面，agent 负责截图。

### README 修改

中英两版同步：顶部 hero；功能段嵌入场景图；CLI 速览嵌入 cli 图。相对路径引用 `docs/images/*`。

## 流程

1. 记录并切换系统外观为浅色
2. 逐场景截图（每张先给用户审阅）
3. 用户确认后修改 README
4. commit（图片 + README）
