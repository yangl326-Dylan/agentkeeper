# Spec Delta

## Purpose

定义应用壳与主交互行为：三面板主窗口（导航树 → 列表 → 详情）、菜单栏常驻入口、扫描反馈与刷新动效、状态语义。它是用户感知 AgentKeeper 质量的直接载体。

## ADDED Requirements

### Requirement: 三面板主窗口
主窗口 SHALL 采用三面板布局：左侧为 agent/skill 导航树（含作用域分组），中部为实体列表（可筛选/搜索），右侧为所选条目详情（含 SKILL.md 渲染、文件列表、历史入口）。布局 SHOULD 遵循 macOS 标准交互（导航侧栏、可调整分隔、键盘导航）。

#### Scenario: 下钻浏览
- **WHEN** 用户在导航树选择某一 agent，再点选列表中的某个 skill
- **THEN** 右侧详情显示该 skill 的元数据、作用域标记与内容预览

#### Scenario: 键盘导航
- **WHEN** 用户在列表中使用键盘上下移动或按下搜索快捷键
- **THEN** 焦点与选中项随之变化，行为与 macOS 系统应用一致

### Requirement: 菜单栏常驻入口
应用 SHALL 提供菜单栏常驻项（MenuBar Extra），展示 agent 安装数量与 skill 总量摘要，并 MUST 提供快速入口（打开主窗口、立即扫描）。

#### Scenario: 状态摘要
- **WHEN** 用户点击菜单栏图标
- **THEN** 面板显示已安装 agent 列表（含各自 skill 数量）与整体状态，可点击进入主窗口对应视图

#### Scenario: 快速扫描
- **WHEN** 用户在菜单栏触发「立即扫描」
- **THEN** 与主窗口触发相同的扫描流程，完成后摘要同步更新

### Requirement: 扫描与状态动效
扫描进行中 SHALL 显示可感知的进度反馈（如呼吸态指示、进度条）；列表与详情的状态切换 MUST 使用轻量、克制的过渡动效（淡入淡出/位移），动效时长与 easing MUST 遵循 macOS 原生质感，MUST NOT 使用打扰性动画。

#### Scenario: 扫描动效
- **WHEN** 一次后台扫描正在进行
- **THEN** UI 出现非阻塞的进行中指示，扫描完成时以平滑过渡呈现新结果

#### Scenario: 尊重系统减少动态效果
- **WHEN** 系统开启了「减少动态效果」辅助功能
- **THEN** 应用以近乎即时的切换呈现，保留状态语义但移除装饰性动画

### Requirement: 风险与状态语义清晰
所有 skill 状态（已启用/已禁用/变更/冲突/权限受限/无法识别）SHALL 以明确的颜色与图标语义区分（如绿色=正常、琥珀=有需注意状态、红色=需处理），状态含义 SHALL 能通过悬停或详情查明。

#### Scenario: 状态一眼可辨
- **WHEN** 用户浏览 skill 列表
- **THEN** 每条记录的状态标记的颜色与图标语义一致，且与系统安全语义（红=危险）不冲突

### Requirement: 错误呈现不阻断
任何扫描/操作失败 SHALL 在界面以非阻断的方式呈现（内联提示、通知或状态标记），MUST NOT 出现未解释的错误弹窗；用户 SHALL 能从错误条目跳到对应修复引导。

#### Scenario: 权限错误引导
- **WHEN** 扫描因目录权限失败
- **THEN** 对应条目显示「权限受限」，点击可查看原因与授权引导，主界面其余部分照常可用
